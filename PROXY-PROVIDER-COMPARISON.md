## 🚀 Quick Setup Guide

### Step 1: Sign Up (5 minutes)

```
1. Go to https://brightdata.com or https://smartproxy.com
2. Create account (email + password)
3. Verify email
4. Add payment method (credit card)
5. Complete KYC (upload ID - BrightData only)
```

---

### Step 2: Get Proxy Credentials (5 minutes)

```
BrightData:
1. Go to "Proxy & Scraping Infrastructure"
2. Click "Add Proxy"
3. Choose "Residential Proxy"
4. Copy credentials:
   - Proxy endpoint: brd.superproxy.io:22225
   - Username: brd-customer-xxxxx
   - Password: xxxxxxxx
```

---

### Step 3: Configure in Crawlee (5 minutes)

```python
# backend/app/services/proxy_config.py

from crawlee.proxy_configuration import ProxyConfiguration

# BrightData configuration
proxy_config = ProxyConfiguration(
    proxy_urls=[
        'http://brd-customer-USERNAME:PASSWORD@brd.superproxy.io:22225',
        # Add more endpoints for rotation
        'http://brd-customer-USERNAME:PASSWORD@brd.superproxy.io:22226',
        'http://brd-customer-USERNAME:PASSWORD@brd.superproxy.io:22227',
    ]
)

# Use in crawler
crawler = PlaywrightCrawler(
    proxy_configuration=proxy_config,
    max_request_retries=3,
)
```

---

### Step 4: Test (5 minutes)

```python
# Test script
import asyncio
from crawlee.crawlers import PlaywrightCrawler

async def test_proxies():
    crawler = PlaywrightCrawler(
        proxy_configuration=proxy_config,
        max_requests_per_crawl=5,
    )
    
    @crawler.router.default_handler
    async def handler(context):
        ip = await context.page.evaluate('() => fetch("https://api.ipify.org?format=json").then(r => r.json()).then(d => d.ip)')
        context.log.info(f'Using IP: {ip}')
        await context.push_data({'ip': ip, 'url': context.request.url})
    
    await crawler.run([
        'https://indeed.com',
        'https://linkedin.com',
        'https://greenhouse.io',
        'https://lever.co',
        'https://google.com',
    ])

asyncio.run(test_proxies())
```

## 💡 Money-Saving Tips

### 1. Start Small

```
Don't buy 50 GB upfront!

Start with:
- 5 GB ($60-75) for testing
- Test on 50 jobs
- Measure success rate
- Then scale up
```

---

### 2. Use Multiple Providers

```
Primary: BrightData (80% of traffic)
Backup: Smartproxy (20% of traffic)

Why:
- Better success rate
- Redundancy if one fails
- Negotiate better rates later
```

---

### 3. Optimize Data Usage

```
Per application:
- Without optimization: ~10 MB
- With optimization: ~5 MB

How:
- Block images (save 3 MB)
- Block CSS (save 1 MB)
- Block fonts (save 500 KB)
- Reuse sessions (save 2 MB)

Savings: 50% = $75/month on 10 GB plan
```

```python
# Block images in Crawlee
crawler = PlaywrightCrawler(
    browser_pool_configuration=BrowserPoolConfiguration(
        page_options={
            'block_resources': True,
            'blocked_resource_types': ['image', 'stylesheet', 'font'],
        }
    )
)
```

---

### 4. Cache Aggressively

```
Don't re-scrape the same job!

Implement:
- 24-hour cache for job listings
- Skip already-applied jobs
- Store job details locally

Savings: 30-50% fewer requests
```

## ⚠️ Red Flags (Avoid These)

### ❌ Free Proxies

```
Why not:
- Already blacklisted by Indeed/LinkedIn
- Slow (shared by thousands)
- Unreliable (disappear randomly)
- Security risk (man-in-the-middle)
- No support

Result: 0-10% success rate, wasted time
```

---

### ❌ Datacenter Proxies

```
Why not:
- Easy to detect (AWS, DigitalOcean IP ranges)
- Indeed blocks immediately
- LinkedIn blocks immediately

Result: 10-20% success rate

Only use for: Testing, non-critical scraping
```

---

### ❌ Shared Proxy Lists

```
Why not:
- Same IP used by hundreds
- Rate limits hit immediately
- No accountability

Result: Constant blocks, poor performance
```
